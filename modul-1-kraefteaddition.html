Rechenweg – Vektorzerlegung

F₁ Zerlegung:

F1x = F₁ · cos(α₁) = 0 kN

F1y = F₁ · sin(α₁) = 0 kN

F₂ Zerlegung:

F2x = F₂ · cos(α₂) = 0 kN

F2y = F₂ · sin(α₂) = 0 kN

Resultierende Gesamtkraft FR (Grün):

FRx = F1x + F2x = 0 kN

FRy = F1y + F2y = 0 kN

FR = √(FRx² + FRy²) = 0 kN

Wirkungswinkel φ = 0°
